# Frontend de MindFit Intelligence

Aplicación React + TypeScript construida con Vite. La documentación general, la arquitectura y las instrucciones completas de instalación están en el [README principal](../README.md).

## Comandos

```bash
npm ci
npm run dev
npm run lint
npm run build
```

Las variables públicas admitidas están documentadas en [`.env.example`](./.env.example). Las variables con prefijo `VITE_` se incorporan al bundle y nunca deben contener secretos.
