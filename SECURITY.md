# Política de seguridad

No publiques credenciales, datos personales, backups de bases ni cadenas de conexión en issues o pull requests.

Para informar una vulnerabilidad, utiliza un aviso de seguridad privado de GitHub en lugar de un issue público. Incluye una descripción, el impacto observado y pasos mínimos para reproducirla, sin adjuntar datos reales.

Las credenciales comprometidas deben revocarse o rotarse aunque luego se eliminen del repositorio.
